# Suleman Awais — Portfolio

Personal portfolio: **Python Developer & AI Engineer**. Live at https://sulemanawais.github.io

Plain static site: no build step, no frameworks, no JavaScript libraries.

| File | What it is |
|---|---|
| `index.html` | Home: hero, what I do, experience, selected work, education, contact |
| `projects.html` | All projects, grouped, with highlights and tech stacks |
| `styles.css` | All styles, animations and mobile layout |
| `favicon.svg` | Site icon |

All illustrations and animations are inline SVG + CSS. Motion switches off automatically for visitors who enable "reduce motion".

## Editing

- Text and projects live directly in the HTML files.
- To deploy, push to `main`. GitHub Pages serves the repository root.
